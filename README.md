# Emile NDAYISENGA — Personal Portfolio<br>

## Description<br>

This is my personal portfolio website showcasing my background, skills, education, <br>projects, certifications, and experience as a **Bachelor of Technology in Information Technology (BTech IT)** student and IT professional.

The portfolio provides an overview of my technical skills, projects, professional experience, <br>and career journey in Information Technology.

## Features<br>

* **Home** — Introduction and personal profile<br>
* **About Me** — Background, education, and professional information<br>
* **Skills** — Technical and professional skills<br>
* **Projects** — Showcase of my IT and software projects<br>
* **Experience** — Professional work experience<br>
* **Education** — Academic background<br>
* **Certifications** — Professional certifications and training<br>
* **Contact** — Ways to get in touch with me<br>
* **Modern Responsive Design** — Works on desktop, tablet, and mobile devices<br>
* **Animated UI** — Modern animations and interactive elements<br>

## How to Run It<br>

You can view the live portfolio through GitHub Pages:<br>

**GitHub Pages:**<br>
https://ndayemile.github.io/endayisenga/<br>

You can also download or clone the repository and open the `index.html` file in a web browser.<br>

## How to Install<br>

Clone the repository using Git:<br>

```bash<br>
git clone https://github.com/ndayemile/endayisenga.git 
```
<br>
Then move into the project folder:<br>

```bash
cd endayisenga 
```
<br>
Open `index.html` in your browser.<br>
